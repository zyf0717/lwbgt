# lwbgt

`lwbgt` is a source-derived, performance-focused C library based on the
Liljegren WBGT v1.1 reference source.

It is not affiliated with or endorsed by the original authors, UChicago
Argonne, or the U.S. Department of Energy.

The exact upstream source and provenance are recorded in `upstream/` and
`UPSTREAM.md`. The optimized derivative is maintained by Yifei/HeatStressDev,
not by the upstream authors.
